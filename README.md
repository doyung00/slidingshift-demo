# 슬라이딩시프트 (SlidingShift) 데모

2조 MONEY · 교대근무 현장을 위한 AI 인수인계·업무 매뉴얼 플랫폼의 최종 발표용 데모입니다.

## 바로 보기

- 웹 링크(GitHub Pages가 켜진 경우): `https://doyung00.github.io/slidingshift-demo/`
- 로컬: `index.html`을 Chrome으로 열면 됩니다. 설치·서버 필요 없음.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 메인 데모 (`slidingshift-demo.html`과 같은 내용, 웹 링크용) |
| `slidingshift-demo.html` | 메인 데모 원본 |
| `slidingshift-web.html` | 웹 배포용 변형본 (모바일 주소창 높이 대응) |
| `시연대본_3분.md` | 3분 시연 대본과 보고서용 설명 문구 |
| `screenshots/` | 시연 화면 캡처 20장 |

## 함께 수정하는 법

1. 파일을 고친 뒤 커밋하고 `main`에 푸시하면 웹 링크에도 1~2분 안에 반영됩니다.
2. `slidingshift-demo.html`을 고쳤다면 `index.html`에도 똑같이 복사해 주세요.
3. 브라우저에서 바로 고치려면 GitHub에서 파일을 열고 연필(✏️) 아이콘을 누르면 됩니다.

## 참고

- 데모의 매장·인물·수치는 모두 가상입니다.
- AI 분석은 시연 안정성을 위해 시나리오·규칙 기반으로 동작합니다.
